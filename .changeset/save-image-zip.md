`useSaveImage({ bytes })` can save a `.zip` (e.g. an image dataset with caption files): a buffer that starts like a zip is held to a 256 MiB cap instead of 50 MiB before sending, and the host validates the archive (entry types png/jpg/jpeg/webp/txt/json/csv, safe paths, UTF-8 names as JSZip writes them, no duplicates, stored or deflate, matching CRC-32s, an allow-list of extra fields, no encryption or zip64, at most 10,000 entries and 1 GiB uncompressed) and saves it as `<name>.zip`. `createMockHost` runs the same validator and reports `application/zip` through `onSaveBytes`. **Build zips with `DEFLATE`** (JSZip `compression: 'DEFLATE'`), **or without `streamFiles` if entries are stored uncompressed.** An uncompressed entry written with `streamFiles` has no size in its header, so it is refused if its bytes contain a zip header signature (`PK\x03\x04` / `PK\x07\x08`) — which random image data does in roughly 1 in 8 files of 256 MiB; the refusal says the same (`… save it with DEFLATE or without streamFiles`). Behavior change: a `bytes` payload that STARTS with `PK\x03\x04` (or `PK\x05\x06`) is now handled as a zip — validated, and refused with the zip's reason if it is not a valid one — where before it was classified as text (and saved as `.txt` if it was valid UTF-8 without NUL). Needs a host with civitai/civitai#8420; an older host refuses a zip with `file type is not allowed` (or `file exceeds the maximum save size` over 50 MiB).

`@civitai/app-sdk`: new subpath `@civitai/app-sdk/save-zip` — the zip validator (`validateSaveZip`, `verifySaveZipInflate`, `looksLikeSaveZip`, `SAVE_ZIP_MAX_BYTES`, `SAVE_ZIP_LIMITS`, `SAVE_ZIP_ALLOWED_EXTENSIONS` and the `SAVE_ZIP_*_ERROR` strings). It is the one copy: the civitai.com host and `createMockHost` both import it. `verifySaveZipInflate(bytes, deflated, signal?)` takes an optional `AbortSignal` and rejects with `SaveZipVerifyAbortedError` when it fires (a caller's deadline, not a verdict on the zip); it feeds the inflater 16 KiB at a time (`SAVE_ZIP_INFLATE_SLICE_BYTES`), which bounds output produced past a lying entry's declared size. Dependency-free; needs `DecompressionStream` (browsers, Node >= 18) for the inflate check.

`@civitai/blocks-react`: the `@civitai/app-sdk` peer floor is unchanged (`>=0.57.0`), and `import '@civitai/blocks-react'` / `'@civitai/blocks-react/testing'` still load on any app-sdk it admits. Only `createMockHost`'s zip validation needs `@civitai/app-sdk` >= 0.85.0: it loads `@civitai/app-sdk/save-zip` on the first zip save, and on an older app-sdk that save rejects with `createMockHost validates a zip with @civitai/app-sdk/save-zip, which needs @civitai/app-sdk >= 0.85.0`.
