**A page can keep a message back without losing it: `before-send`'s `queue(waiting)`.** The message shows at once as the viewer's bubble, marked with `waiting` (and said once to screen readers), with its files, and the chat holds; it goes, as it is and with no second `before-send` or Buzz grant, once the page calls `release()` on the returned `QueuedMessage` and the chat can send. `queue()` works only from the listener itself (later it throws) and once per message. The waiting bubble has Edit. A message that will not go (`cancel()`, `QUEUE_TIMEOUT_MS` = 3 minutes, or another chat opened) comes back into an empty message box with its files, or, when the viewer typed there or is dictating, as a "This message was not sent" alert with Put it back and Dismiss. Signed out or signed in as someone else, these are dropped unseen. New `giveBack(text)` brings back a message the page could not send the same way (it returns `false`, doing nothing, before the chat has started or while it is signed out). See "A message that waits" in the README.
