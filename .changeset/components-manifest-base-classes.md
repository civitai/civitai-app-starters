`custom-elements.json` now lists what each element inherits. The base classes were never analysed, so every form control (checkbox, number-input, radio-group, segmented-control, select, slider, switch, text-input, textarea) was missing the attributes all of them share — `name`, `value`, `label`, `description`, `error`, `required`, `disabled`, `size` — and image, video and audio were missing `src`, `alt`, `fallback`, `pending`, `blocked` and `status`, along with their `load` and `error` events. `<civitai-text-input>` listed 5 attributes; it now lists 13. Each inherited entry carries `inheritedFrom`, and `CivitaiElement`, `CivitaiField` and `CivitaiMediaElement` are declared as modules of their own, with no tag: the set of elements and tags is unchanged. Every element also lists the `change` and `invalid` events `CivitaiElement` re-dispatches out of its shadow root. An entry an element declares itself stays its own (segmented-control's `size` keeps its own type), and an inherited one names the nearest class that declares it. No code changes; only the manifest's content.
